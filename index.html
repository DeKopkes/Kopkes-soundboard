Geluid instellen

Zo gebruik je jouw soundboard

Op iPhone/iPad: open deze pagina in Safari en kies Deel → Zet op beginscherm. Daarna opent de Soundboard als een app.

  1. Open deze Soundboard lokaal in Chrome, Edge of Safari. De geluiden worden in de set zelf opgeslagen; voor het afspelen van een opgeslagen set is geen internet nodig.
  2. Voeg MP3- of WAV-bestanden toe, ook meerdere tegelijk. Andere audioformaten werken als je browser ze ondersteunt. Je kunt 50 geluiden of meer toevoegen.
  3. Klik op de naam om een cue klaar te zetten; GO speelt deze af. ‘Volgende’ zet het volgende geluid klaar. De afspeelknop op een kaart speelt dat geluid meteen.
  4. Via ‘Instellen’ op iedere kaart regel je fades, volume, herhalen, start/eind en een eigen sneltoets. Stop op een kaart gebruikt de fade-out. STOP ALLES en Esc stoppen onmiddellijk.
  5. Met ‘Meerdere tegelijk’ mogen geluiden overlappen. Anders stopt het vorige geluid direct wanneer je een nieuw geluid start.
  6. Klik na wijzigingen op ‘Set opslaan’. Kies een naam; er wordt een nieuw HTML-bestand gedownload, mét alle geluiden en instellingen, zodat die set zelfstandig offline kan worden geopend. Open dat bestand bij je volgende optreden. Ook op een andere laptop werkt het offline.

Een browserkopie wordt waar mogelijk automatisch bewaard op dit apparaat. Vertrouw voor een optreden op je opgeslagen setbestand; verplaatsen, browsergegevens wissen of privévensters kunnen die browserkopie verwijderen.

Alle audio blijft lokaal. Een opgeslagen set kan groot worden: originele audiobestanden worden volledig opgenomen. Controleer voor een optreden je set en de gekozen audio-uitgang.
